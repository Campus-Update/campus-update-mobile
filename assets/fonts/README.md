Archivo — the sole typeface, in two weights only.

| File | Weight |
|---|---|
| `Archivo-Regular.ttf` | 400 — body and labels |
| `Archivo-Medium.ttf` | 500 — headings, buttons, active navigation |

Static instances of the Archivo variable font, taken from Google Fonts (v25).
Licensed under the SIL Open Font License 1.1 — see `OFL.txt`.

To refresh, read the TTF URLs out of the Google Fonts CSS API and download them:

```bash
curl -s -A "Mozilla/4.0" \
  "https://fonts.googleapis.com/css2?family=Archivo:wght@400;500"
```
